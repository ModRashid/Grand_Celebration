# The Grand Celebration — Wedding Invitation

This repository contains the existing sage-green and ivory wedding invitation, packaged for Streamlit Community Cloud.

## Files
- `app.py` — invitation website and its styling/interactions
- `requirements.txt` — Python dependency for Streamlit

## Publish for free
1. Sign in to GitHub and create a **Public** repository, e.g. `muhammad-areeba-invitation`.
2. Upload `app.py` and `requirements.txt` to the repository root (not inside another folder).
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Choose **Create app**, select your repository, branch `main`, and main file path `app.py`.
5. Deploy. Streamlit will provide a public URL similar to `https://your-app-name.streamlit.app`.
6. Open that URL in a private/incognito window to verify it works, then share it with guests.

The exact URL is assigned by Streamlit when the app is deployed. You cannot get a live public URL from GitHub upload alone. A custom domain like the example you shared generally requires domain registration and additional configuration; the free `streamlit.app` address is the easiest route.
