# Valima Invitation Website

A responsive, mobile-friendly Streamlit invitation page for the Valima of Muhammad Abdul Rashid and Areeba Fatima.

## Included features
- Sage-green, ivory and antique-gold palette with floral corner details
- Arabic Bismillah and English translation
- Invitation wording followed by large couple names (names are not repeated in the invitation paragraph)
- Date and live countdown to 7:30 PM Pakistan Standard Time on 13 November 2026
- Venue address and Google Maps link
- RSVP WhatsApp links for all three hosts
- Closing Arabic dua and English translation

## Deploy / update on Streamlit Community Cloud
1. Upload `app.py` and `requirements.txt` to the root of your GitHub repository.
2. Commit the changes. If your Streamlit app is already deployed, it should redeploy automatically.
3. For a new deployment, visit https://share.streamlit.io/, connect GitHub, select the repository and branch, and set the main file to `app.py`.

The invitation uses Google Fonts for enhanced typography. If fonts are blocked, browser fallback fonts will be used. No API keys or secrets are required.
