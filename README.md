# Muhammad Abdul Rashid & Areeba Fatima — The Grand Celebration

A mobile-friendly wedding invitation website with a deep forest-green, ivory and antique-gold palette, elegant typography, scrolling sections, venue map, WhatsApp RSVP, host contacts and calendar download.

## Deploy on Streamlit Community Cloud
1. Download and extract the ZIP archive.
2. Create a **public** GitHub repository (for example `muhammad-areeba-invitation`).
3. Upload `app.py` and `requirements.txt` to the repository root, then commit the changes.
4. Sign in at https://share.streamlit.io/ with GitHub.
5. Choose **Create app**, select your repository and branch `main`, and set the main file path to `app.py`.
6. Select **Deploy**. After deployment, copy the real public URL provided by Streamlit and test it on a phone before sharing.

No API key or secrets are required. The deployed invitation is not live until you complete these steps.
