# Valima Invitation Website

A mobile-friendly, single-page sage-green and white floral Valima invitation for Muhammad Abdul Rashid and Areeba Fatima.

## Files
- `app.py` — complete Streamlit invitation website
- `requirements.txt` — Python dependency

## Update your GitHub project
1. Open your existing GitHub repository.
2. Replace the existing `app.py` with this revised `app.py`.
3. Keep or replace `requirements.txt` with the included file.
4. Commit the changes.
5. If already deployed on Streamlit Community Cloud, it should redeploy automatically. If not, visit https://share.streamlit.io/, choose **Create app**, select your repository and branch, and set the main file path to `app.py`.

No API keys or secrets are required. The Google Maps button opens a Maps search for the venue, and each RSVP contact opens WhatsApp.
