# Muhammad Abdul Rashid & Areeba Fatima — Valima Invitation

A mobile-friendly Valima invitation website with a soft sage-green and white floral theme. It includes the Bismillah and English translation, invitation wording, date/time and venue, Google Maps, WhatsApp RSVP, host contacts, and an add-to-calendar download.

## Deploy or update on GitHub + Streamlit Community Cloud
1. Download and extract the ZIP archive.
2. Upload `app.py` and `requirements.txt` to the root of your GitHub repository, replacing the old versions, then commit the changes.
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. If your app is already deployed, the commit should trigger an update automatically. Otherwise choose **Create app**, select your repository and branch `main`, and set the main file path to `app.py`.
5. After deployment finishes, open the public URL and test the invitation on a phone before sharing it.

No API keys or secrets are required. The website is not public until it is deployed through Streamlit Community Cloud.
